# Backlog

Полный бэклог для следующих итераций. Ничего из перечисленного не реализовано — список зафиксирован для последующего планирования, не как активные задачи.

## Мелкая полировка (низкий приоритет, технически простое)

- **#13 — лёгкое мерцание контента (один кадр) при client-side навигации между страницами.** Требует `loading.tsx`/Suspense boundaries на каждый роут — архитектурное, не косметическое решение.
- **Show/hide password на полях логина/регистрации.** Простой UI-фикс (toggle-иконка глаза в поле пароля).

## Функциональные расширения (средний приоритет)

- **Русский язык — полноценная локализация (i18n).** Переключатель языка, перевод всех строк UI, возможно и генерируемых AI-текстов (отчёты, findings) — требует продуманной архитектуры (`next-intl` или аналог).
- **Светлая тема.** Вся дизайн-система сейчас построена вокруг тёмной палитры (`#05070A` фон, glow-эффекты) — светлая тема потребует параллельного набора токенов, не просто инверсии цветов.

## Продуктовое позиционирование (стратегическое, самое крупное)

- **Адаптация под малый/средний бизнес, не только инвесторов.** Самый масштабный пункт. Требует отдельного продуктового решения: либо (а) SMB использует Kora, чтобы анализировать себя перед питчем инвесторам/при подготовке к продаже бизнеса, либо (б) SMB использует Kora для анализа партнёров/поставщиков/конкурентов при M&A или due diligence со своей стороны. Это меняет тексты, онбординг, возможно и сам набор извлекаемых метрик — стоит обсуждать отдельно, не как обычный технический тикет.
